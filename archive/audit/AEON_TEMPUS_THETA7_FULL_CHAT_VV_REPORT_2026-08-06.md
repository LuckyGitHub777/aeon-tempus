## 6. Material Findings and Defects

### Finding 1: Completion is self-attested, not substantively validated

**Severity:** High for claimed workflow integrity

The completion gate requires:

- seven chamber checkboxes,
- one grounded action,
- four action-condition confirmations,
- and one grounding selection.

It does **not** require substantive text in most chamber fields. A user can check all seven chamber boxes without entering meaningful observations, evidence, interpretations, reconciliation content, or lessons.

**Impact:** `7/7 complete` confirms the user checked the sequence, not that the reasoning process was actually performed.

**Required correction:** Either:

1. require minimum substantive entries in selected critical fields, or
2. explicitly relabel completion as `Self-attested sequence completion` and preserve the distinction in exports.

Recommended required fields:

- Arrival
- Obscuration
- Directly observed
- Unresolved uncertainty
- Selected action
- Retained lesson
- Grounded return activity

### Finding 2: “FINAL VERIFIED” overstates verification scope

**Severity:** High for configuration and public credibility

The artifact passed static and controlled functional checks. It has not passed:

- actual local-file execution on target user systems,
- hosted deployment validation,
- Firefox, Edge, or Safari testing,
- formal accessibility audit,
- real-user usability testing,
- security review beyond static local behavior,
- or outcome validation.

**Required correction:** Treat v1.1.0 as a release candidate or clearly define the verified scope in the filename and documentation.

### Finding 3: Pilot consent is local-only but can be misunderstood

**Severity:** Medium

The optional pilot-metrics consent checkbox records consent in the local state and exports. No information is transmitted or aggregated.

**Required correction:** Add visible text next to the checkbox:

> This records consent in your local/exported record only. This page does not transmit or collect metrics.

### Finding 4: Local records are plaintext

**Severity:** Medium

Data is saved in browser `localStorage` without encryption. This is appropriate for a simple offline prototype but may expose sensitive reflections to anyone with access to the same browser profile or device.

**Required correction:** Add an in-interface privacy notice near Save and Reset. Avoid encouraging entry of secrets, protected health information, classified information, or highly sensitive personal data.

### Finding 5: Self-reported clarity is a signal, not outcome validation

**Severity:** Medium

The proof assessment is based on:

- seven self-checked steps,
- and a user-selected clarity-before/after delta.

The current copy does contain cautionary boundaries, which is good. However, the UI still visually elevates `Positive signal` in a way that may be overread.

**Required correction:** Preserve `session-level self-reported signal` in the primary status label, not only in supporting text.

### Finding 6: Legacy storage is copied, not retired

**Severity:** Low

v1.1 creates a new storage key from v1.0 but retains the legacy key. Reset clears both.

**Recommended correction:** After successful migration, mark or remove the legacy key, or document that it remains as rollback data.

### Finding 7: Unicode export filenames may reduce portability

**Severity:** Low

Exports use the `Θ` character in filenames. Modern Windows supports this, but some scripts, older tools, ZIP pipelines, and cross-platform automation may handle ASCII filenames more reliably.

**Recommended correction:** Use an ASCII filename such as `THETA-7-YYYYMMDD-HHMMSS` while preserving `Θ-7` inside the record.

### Finding 8: No distributed test evidence

**Severity:** Medium for repository readiness

The HTML contains no accompanying automated test suite, browser-test record, accessibility report, manifest, or change log.

**Required for public engineering release:** Package the artifact with reproducible verification evidence.

### Finding 9: One earlier conversation reference was irrelevant

An earlier explanation referenced a separately loaded `AI Governance for Peace` file. That statement did not contribute to AEON-TEMPUS or Theta-7 and should not be treated as part of the controlling project record.

# Validation Plan

## Current status
v1.1.1-rc1 is a technically verified pilot candidate, not a broadly validated product.

## Required public-pilot validation
1. Verify the GitHub Pages deployment returns the expected `index.html`.
2. Open `index.html` directly from a target Windows device.
3. Test current Chrome, Edge, Firefox, and Safari where applicable.
4. Perform a WCAG 2.2 AA-oriented audit and screen-reader checks.
5. Run a controlled 5–10 person pilot using safe, ordinary scenarios.

## Pilot measures
Predefine thresholds before testing:
- independent completion rate;
- critical misunderstanding rate;
- actionability rate;
- usability rating;
- abandonment chamber;
- safety concerns;
- completion time;
- clarity-before/clarity-after delta.

Clarity change is self-reported session evidence only. Do not convert a positive delta into a general effectiveness claim without repeated, appropriately designed evidence.

# Validation Plan

## Current status
v1.1.2-rc1 is a UX-corrective, technically verified pilot candidate, not a broadly validated product.

## Required pilot validation
1. Download the current GitHub Release HTML and `RELEASE_SHA256SUMS.txt`; verify the release checksum succeeds against the downloaded filename.
2. Open the downloaded HTML directly on target Windows and macOS devices and confirm the local-file privacy/session-only behavior.
3. Test current Chrome, Edge, Firefox, and Safari where applicable.
4. Perform a WCAG 2.2 AA-oriented manual audit and screen-reader checks in addition to automated scanning.
5. Run a controlled 5–10 person pilot using safe, ordinary scenarios.
6. If GitHub Pages is later enabled, verify the hosted page separately; hosted deployment is an optional presentation layer, not proof of product effectiveness.

## Pilot measures
Predefine thresholds before testing:
- independent completion rate;
- critical misunderstanding rate;
- actionability rate;
- usability rating;
- abandonment chamber;
- safety concerns;
- completion time;
- explicitly rated clarity-before/clarity-after delta.

Clarity change is self-reported session evidence only. Do not convert a positive delta into a general effectiveness claim without repeated, appropriately designed evidence.
